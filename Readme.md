## ⚡ Tech Stack & Architecture

- **Core**: Semantic HTML5, Vanilla CSS3 (Custom Design System & CSS Variables), Modern Vanilla JavaScript (ES6+).
- **Typography**: Space Mono (Display & Code), JetBrains Mono (Body/UI), Caveat (Handwritten human annotations & sticky notes).
- **Audio Feedback**: Built-in Web Audio API mechanical sound synthesizer (no external audio assets required, toggleable SFX).
- **Responsiveness**: Fully responsive across Mobile (<640px), Tablet (640px–1024px), and Desktop (>1024px) viewports.

## 🚀 Key Features

1. **Monospace & Human Design System**:
   - Cyber-monospace editorial style with warm dark palette (`#0b0d13`), neon coral (`#ff5e7e`), lime (`#a3e635`), cyan (`#22d3ee`), and real-life sticky note accents.

4. **SIH Mission Blueprint**:

5. **The Squad (Team Roster)**:
   - Interactive member cards with roles, superpowers, caffeine intake stats, and category filtering (Core & Lead, AI/ML, Fullstack & Infra, Design).

   - Interactive sliders (Sprint duration, Chai consumed, Bugs squashed, Panic level) generating real-time Hackathon readiness scores.

   - Smooth hamburger navigation for smaller screen sizes.

## 💻 How to Run Locally

Simply open `index.html` in any modern web browser, or serve it using any local HTTP server:

```bash
# Option 1: Python
python -m http.server 3000

# Option 2: Node npx
npx serve .

# Option 3: VS Code Live Server extension
```

Visit `http://localhost:3000` in your browser!
